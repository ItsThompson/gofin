# Expected post-change shape (bounded errgroup, dashboardFanoutLimit=5):
#   - call counts unchanged for trends (1 per non-nil period)
#   - historical drops to <=4 reads (distinct periods; priorPeriods[0] read once)
#   - wall-clock ~ max·ceil(n/limit): months=12 drops ~3.9x, historical ~4.8x;
#     months=1 is flat (one read, so errgroup setup makes it marginally slower)
